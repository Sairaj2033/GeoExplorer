# 🌍 React-GeoExplorer App

### React-Based Location & Weather Explorer

> A React-powered location explorer that allows users to search for places and view weather information through a clean, responsive interface.

## ✨ Features

- 🌍 Search locations by city name
- 🌤️ Fetch and display weather information
- 🌡️ Temperature, humidity & min/max temperature
- 🖼️ Dynamic location-based visuals
- ⚡ React component-based architecture
- 📱 Responsive user interface
- 🔄 Dynamic API data rendering
- 🎨 Clean and simple UI

## 🚀 Installation

```bash
git clone https://github.com/Sairaj2033/React-GeoExplorer-App.git

cd React-GeoExplorer-App

npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL provided by Vite.
